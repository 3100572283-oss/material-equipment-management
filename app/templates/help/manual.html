系统概述与架构

1.1 系统定位

本系统是一款面向建筑施工企业的物资设备综合管理平台，覆盖物资采购、入库、出库、库存、对账、付款、设备管理、周转材管理等全业务流程。采用"公司级主数据统一 + 项目级数据隔离"的架构，支持多项目并行管理。

1.2 组织架构模型
总公司
  ├── 总公司机关（物资管理部、财务管理部、综合办公室）
  ├── 分公司A
  │     ├── 项目部1（物资组、工程组、财务组）
  │     └── 项目部2（物资组、工程组）
  └── 分公司B
        └── 项目部3（物资组、设备组）
1.3 数据层级
数据类型层级说明
物资分类、物资主库、供应商主库、字典项公司级所有项目共享，统一维护
常用物资、常用供应商、用料单位、班组、工号项目级各项目独立，互不可见
合同、入库单、出库单、对账单、发票、付款项目级严格按项目隔离
设备台账、周转材台账项目级按项目模块开关控制是否启用
1.4 模块开关配置

每个项目可独立配置启用/关闭以下模块：

  • 周转材模块：管理模板、脚手架等可重复使用材料
  • 设备管理模块：管理自有/租赁设备台账、维修、折旧
  • 审批流程模块：开启后单据需审批才生效，关闭则直接生效
  • 批次保质期模块：对有保质期要求的物资进行批次跟踪
  • 质检流程：入库时增加待检/合格状态流转
  • AI 功能：OCR 识别、智能补全等 AI 辅助功能

核心业务流程

2.1 标准采购业务流

流程：采购申请 → 采购合同 → 入库单 → 对账单 → 发票 → 付款申请 → 付款台账

① 采购申请：项目部提出物资需求，填写物资名称、规格、数量、需求日期
② 采购合同：根据采购申请与供应商签订合同，约定单价、数量、税率
③ 入库单：物资到货后录入入库单，关联合同后自动带入单价
④ 对账单：按月/按期间与供应商核对入库数量与金额
⑤ 发票：收到供应商发票后录入，与合同关联
⑥ 付款申请：根据对账结果申请付款
⑦ 付款台账：记录实际付款信息
2.2 库存管理业务流

流程：期初库存 → 入库 (+) → 出库 (-) → 盘点调整 → 期末结账

① 期初库存：系统初始化或新项目上账时录入期初库存
② 入库：采购入库（+）、调拨入库（+）、盘盈入库（+）
③ 出库：工程领用（-）、调拨出库（-）、盘亏出库（-）、报废出库（-）
④ 盘点：定期盘点，实盘数量与系统库存差异自动生成盘盈/盘亏单
⑤ 期末结账：月度/季度末进行结账，生成库存快照，结账后期间单据锁定
2.3 设备管理业务流

流程：设备台账 → 维修记录 → 租赁结算 → 折旧计算

① 设备台账：登记设备基本信息（名称、型号、购置日期、原值）
② 维修记录：记录设备维修保养信息
③ 租赁结算：租赁设备按月/按期间生成结算单
④ 折旧计算：自有设备按直线法自动计算月度折旧
2.4 周转材管理业务流

流程：周转材台账 → 领用 → 归还 → 租赁费结算

① 周转材台账：登记钢管、模板、脚手架等周转材料
② 领用：记录领用数量、领用单位、预计归还日期
③ 归还：记录实际归还数量，计算损耗
④ 租赁费结算：按租赁期间和单价生成结算单

基础数据管理

3.1 物资分类管理

采用三级分类结构，编码规则如下：

  • 一级分类：MC01、MC02、MC03...（MC + 2位序号）
  • 二级分类：MC0101、MC0102...（父级编码 + 2位序号）
  • 三级分类：MC010101、MC010102...（父级编码 + 2位序号）

关键约束：只有三级分类（末级）才能关联物资；已有物资关联的末级分类禁止删除；有子分类的一级/二级分类需先删除所有子分类才能删除。

3.2 物资主库管理

物资编码自动生成规则：所属三级分类编码 + 3位流水号，如 MC010101001。

物资信息包括：名称、规格型号、单位、所属分类、备注。支持 Excel 批量导入。

3.3 供应商管理

供应商评价维度（四维评分，满分100）：

维度权重说明
质量30%物资质量合格率
价格25%价格竞争力
交货期25%按时交货率
服务20%售后服务质量

等级划分：A(>=85分)、B(70-84分)、C(60-69分)、D(<60分)。D级供应商新增合同时会弹出风险提示。

3.4 用料单位与工号

用料单位：分为内部班组和外部分包商两类。出库单需选择领料单位，用于成本归集。每个用料单位下可设置多个领用小组，记录领料人姓名和电话。

工号：编码规则 GH + 年月日 + 3位序号。出库单可关联工号，便于按工号统计用料成本。

采购管理

4.1 采购申请

操作步骤：

  1. 进入"采购申请"菜单，点击"新增申请"
  2. 填写申请部门、申请人、需求日期
  3. 添加物资明细：选择物资、填写申请数量、备注
  4. 保存并提交（如审批模块开启，则进入审批流程）

业务规则：

  • 支持部分转合同：一份采购申请可多次转合同，直到申请量用完
  • 已转合同的申请标记为"已完成"状态
  • 普通用户仅能查看自己的采购申请，管理员可查看全部
4.2 采购合同

操作步骤：

  1. 进入"合同台账"菜单，点击"新增合同"
  2. 填写合同基本信息：合同编号、名称、供应商、签订日期、税率
  3. 添加合同明细：选择物资、填写数量、含税单价、单价类型（固定/浮动）
  4. 系统自动计算：不含税单价 = 含税单价 / (1 + 税率/100)
  5. 保存合同

业务规则：

  • 合同金额 = SUM(数量 × 含税单价)
  • 合同明细显示"入库进度"：已入库量 / 合同量，超量时进度条变红
  • 支持关联查看来源采购申请单
  • 合同可关联发票和付款记录，自动统计开票金额和付款金额

入库管理

5.1 入库类型
入库类型业务场景库存影响
采购入库正常采购到货入库增加库存
调拨入库其他项目调拨入库增加库存
盘盈入库盘点发现实物多于账面增加库存
退货入库供应商退货重新入库增加库存
5.2 操作步骤
  1. 进入"入库管理"，点击"新增入库单"
  2. 选择入库类型、供应商、合同（如有）
  3. 填写入库日期、经办人、车牌号等信息
  4. 添加物资明细：选择物资、填写数量、单价
  5. 关联合同时，系统会自动带入合同约定的单价
  6. 保存并提交审批
5.3 超量入库控制

当入库数量超过合同剩余量时，系统会弹出警告：

  • 调整数量：自动将数量调整为合同剩余量
  • 强制提交：保留原数量提交，需管理员权限

超量比例阈值在"系统配置"中设置（contract_over_ratio），默认 0% 即不允许超量。

5.4 质检流程（如模块开启）

入库单状态流转：草稿 → 待检 → 合格/不合格 → 审批 → 通过/驳回

  • 提交后先进入"待检"状态
  • 质检员检验后标记"合格"或"不合格"
  • 合格后才进入审批流程
  • 审批通过后库存才真正增加

出库管理

6.1 出库类型
出库类型业务场景库存影响
工程领用班组/分包商领用物资减少库存
调拨出库调拨给其他项目减少库存
退货出库退回给供应商减少库存
报废出库物资报废处理减少库存
盘亏出库盘点发现实物少于账面减少库存
6.2 操作步骤
  1. 进入"出库管理"，点击"新增出库单"
  2. 选择出库类型、领料单位、工号（工程领用时）
  3. 填写出库日期、领料人等信息
  4. 添加物资明细：选择物资、填写数量
  5. 系统实时校验库存，库存不足时提示（可配置是否允许负库存）
  6. 保存并提交审批
6.3 退库入库

领用物资退回时，创建"退库入库单"：

  • 选择原出库单关联，系统带入原出库物资信息
  • 填写实际退库数量（可少于原领用数量）
  • 退库入库单审批通过后，库存增加

库存管理

7.1 库存查询

实时查看各物资的当前库存数量，支持按物资名称、规格、分类筛选。库存不足的物资以红色背景警示。点击"流水"按钮可查看该物资的所有出入库历史记录。

7.2 库存盘点

操作步骤：

  1. 进入"盘点管理"，点击"新增盘点单"
  2. 选择盘点范围（全库或按分类）
  3. 系统带出当前库存数量作为账面数
  4. 录入实盘数量
  5. 系统自动计算差异：差异 = 实盘 - 账面
  6. 确认盘点后，系统自动生成盘盈入库单或盘亏出库单

状态流转：草稿 → 盘点中 → 已确认/已作废

注意：仅草稿状态可删除；已确认盘点单作废时需同时冲销生成的出入库单。

7.3 项目调拨

操作流程：

  1. 调出项目创建调拨单，选择调入项目、物资、数量
  2. 提交审批（如开启审批模块）
  3. 审批通过后，调出方确认出库（扣减库存）
  4. 调入方确认入库（增加库存，可修改实际入库数量）

差异处理：入库量小于出库量时，差异部分记录为运输损耗。

状态流转：草稿/待出库 → 已出库 → 待入库 → 已完成/已取消

对账与财务

8.1 对账管理

操作步骤：

  1. 进入"对账管理"，点击"新增对账单"
  2. 选择供应商、对账期间
  3. 点击"拉取数据"，系统自动获取该期间内未对账的入库记录
  4. 核对数量，如需调整可修改单价
  5. 确认对账后，入库单标记为"已对账"
  6. 可打印标准对账单供双方签字存档

业务规则：已对账的入库单不能删除，如需删除请先撤销对账。

8.2 发票管理

在合同详情页"关联发票"标签下新增发票：

  • 填写发票代码、发票号码、开票日期、含税金额、税率
  • 系统自动计算不含税金额
  • 可上传发票扫描件
8.3 付款管理

付款申请：填写申请金额、付款方式、关联合同，提交审批。

付款台账：记录实际付款信息，包括付款日期、金额、方式、备注。

设备管理

9.1 设备台账

设备编码：SB + 序号，自动生成。

设备分类：自有设备 / 租赁设备

信息字段：名称、型号、规格、购置日期、原值、使用部门、存放位置、状态（在用/闲置/维修中/报废）

9.2 维修记录

记录设备故障、维修内容、维修费用、维修日期、维修后状态。

9.3 租赁结算

租赁设备按月/按期间生成结算单，计算租赁费用。

9.4 折旧计算

自有设备按直线法自动计算月度折旧：

月折旧额 = (原值 - 预计净残值) / (使用年限 × 12)

周转材管理

10.1 周转材台账

管理可重复使用的周转材料，如钢管、模板、脚手架等。记录名称、规格、单位、初始数量、当前数量。

10.2 领用与归还

领用：记录领用数量、领用单位、预计归还日期。

归还：记录实际归还数量，系统计算损耗数量 = 领用 - 归还。

10.3 租赁费结算

按租赁期间和单价生成结算单，支持按天/按月计算。

审批流程

11.1 流程配置

管理员在"审批流程管理"中配置各业务类型的审批流程：

  • 支持多节点审批
  • 每个节点可设置审批角色或指定审批人
  • 支持会签（需全部通过）和或签（任一通过）
  • 支持条件分支（如金额大于某值需额外审批）
11.2 分级审批
级别配置方式说明
公司级默认管理员统一配置所有项目默认沿用
项目级自定义项目经理配置仅覆盖本项目的对应流程
关闭审批模块开关关闭单据提交后直接生效
11.3 审批操作

提交人：可撤回待审批的单据。

审批人：可审批通过或驳回，不能审批自己提交的单据。

状态流转：草稿 → 待审批 → 审批中 → 已通过/已驳回 → 已撤回

数据影响：审批通过后单据正式生效（影响库存、金额统计等），驳回/撤回后相关数据回滚。

数据权限

12.1 权限层级
数据权限可见范围适用角色
全部数据所有项目数据超级管理员、公司物资部长、财务主管
本部门及下级本部门及子部门数据项目经理
本部门数据仅本部门数据项目物资员
仅本人仅自己创建的数据普通录入员
12.2 全部项目模式

拥有"全部数据"权限的用户可切换至"全部项目"模式，此时列表会显示"所属项目"列，可查看所有项目的数据汇总。

12.3 多项目兼职

一个用户可关联多个项目，其中一个是主项目。切换项目时，数据自动按当前项目过滤。

期末结账

13.1 结账前检查

系统在执行结账前自动检查以下条件：

  • 是否存在未审核通过的入库单
  • 是否存在未对账的入库单
  • 是否存在未审核通过的出库单
  • 是否存在库存为负的物资

如有以上问题，系统会列出并阻止结账，需处理完毕后才能继续。

13.2 结账操作
  1. 进入"期末结账"菜单
  2. 选择要结账的期间（格式：YYYY-MM）
  3. 点击"检查"按钮，查看是否存在问题
  4. 检查通过后，点击"执行结账"
  5. 系统自动生成该期间所有物资的库存快照（期初、入库、出库、期末）
13.3 结账后限制

已结账期间：

  • 禁止新增/修改该期间的出入库单据
  • 禁止删除该期间的相关单据
  • 可作为下一期间的期初数据依据
13.4 反结账

如需修改已结账期间的数据，需先执行反结账：

  1. 选择已结账期间
  2. 填写反结账原因
  3. 确认反结账后，该期间数据恢复可编辑状态
  4. 反结账会删除该期间的库存快照

系统管理

14.1 用户管理

管理员可添加用户、分配角色、设置数据权限、分配项目。支持禁用/启用用户账号。

14.2 数据备份

支持手动备份数据库，备份文件存储在项目的 backups 目录中。支持从备份文件恢复数据。

14.3 系统配置

关键配置参数：

参数名说明默认值
contract_over_ratio允许超量入库比例（%）0
enable_negative_stock是否允许负库存出库false
backup_retention_days备份保留天数30
14.4 操作日志

系统自动记录所有操作日志，包括操作人、时间、模块、操作类型、请求参数、执行结果等。支持按条件查询和导出。
