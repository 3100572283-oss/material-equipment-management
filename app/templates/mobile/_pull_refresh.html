{# 移动端下拉刷新 + 上拉加载组件 #} {# 用法： 1. 下拉刷新：MobilePullRefresh.bindRefresh({ container: document.querySelector('.m-content') 或 滚动容器, onRefresh: function(done){ ...; done(); } }); 2. 上拉加载：MobilePullRefresh.bindLoadMore({ container: document, onLoadMore: function(done){ ...; done(); }, // done(false) 表示没有更多 threshold: 100 // 距离底部多少像素触发 }); #}
